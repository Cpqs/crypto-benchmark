# Crypto Benchmark

Benchmark для практического сравнения двух реализаций шифрования фотографий:

- AES-256-GCM
- STB / Bee2

Проект сравнивает производительность криптографии в реальном приложении с FastAPI, HTTP API и базой данных.

> **Важно:** это не математическое сравнение алгоритмов. Сравниваются конкретные программные реализации на конкретной системе.

## AES-256-GCM

AES реализован через библиотеку `cryptography`.

Используется AES-256-GCM с 256-битным ключом и случайным 12-байтным nonce.

AES-GCM обеспечивает конфиденциальность и аутентификацию данных.

Время шифрования измеряется непосредственно вокруг:

```python
aes.encrypt(...)
````

Расшифрование:

```python
aes.decrypt(...)
```

## STB / Bee2

STB реализован через библиотеку Bee2 и Python wrapper.

Шифрование выполняется через:

```python
bee2_lib.bashPrgEncr(...)
```

Расшифрование:

```python
bee2_lib.bashPrgDecr(...)
```

Измеряется непосредственно время выполнения криптографической функции.

STB использует `ProcessPoolExecutor`, поэтому полное время обработки может быть выше из-за дополнительного overhead wrapper и передачи данных между процессами.

## Что измеряется

Для каждой реализации выполняются:

* upload;
* download;
* encryption;
* decryption.

Основные показатели:

* `crypto_time_ms` — время непосредственно криптографической операции;
* `upload_time_ms` — полное время обработки upload;
* `download_time_ms` — полное время обработки download;
* `request_time_ms` — полное время HTTP-запроса.

Для проверки целостности фотографий используется SHA-256.

## Методика

По умолчанию:

```text
1000 фотографий
100 KB каждая
```

Обе реализации получают одинаковые данные.

Для результатов рассчитываются:

* total;
* average;
* median;
* min;
* max;
* standard deviation.

Также определяется, какая реализация быстрее, во сколько раз и на сколько процентов.

## Интерпретация

Например:

```text
Encryption,0.0363,0.2614,AES,7.2082,86.1269
```

означает, что AES в среднем выполняет encryption примерно в 7.2 раза быстрее STB.

Важно учитывать, что `crypto_time_ms` и полное время сервиса — разные показатели.

## Ограничения

Результаты характеризуют конкретные реализации AES и STB/Bee2 на конкретной системе.

На результат влияют:

* CPU;
* Docker;
* Python и версии библиотек;
* размер данных;
* реализация wrapper;
* аппаратное ускорение AES.

> В данной реализации и на данной тестовой системе AES-256-GCM показал меньшее время выполнения криптографических операций по сравнению с используемой реализацией STB/Bee2.
